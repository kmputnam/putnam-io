# Site audit and dependency update

Prepared on October 12, 2026. The source is the `putnam-io` repository. Kyle confirmed that the site will serve as a professional profile and contact page. Kyle also confirmed that the existing Cloudflare hosting will remain.

## Audit scope

The review covered all source pages, both content collections, layouts, styles, assets, package versions, repository files, and deployment configuration. It also covered the current public site and Cloudflare build settings.

The browser procedure covers all eight published pages and the custom 404 page. It uses the built site through the local Cloudflare runtime. Public tests use the same procedure after deployment.

The source review found no application secrets or unsafe HTML insertion. The site has no application server or client application scripts. This review does not establish the accuracy of biography or work claims.

## Build and release evidence

The previous source check and build passed with Astro 5. The updated source check and build passed with Astro 7. The updated source check reports zero errors, warnings, and hints.

A clean temporary copy installed 307 packages from the lockfile. It passed the source check and generated nine HTML pages. Eight pages contain published content. The remaining page is the custom 404 page.

Wrangler 4.149.0 passed the deployment dry run. This result establishes that the static assets can be packaged. It does not establish a remote deployment.

The saved evidence directory is `artifacts/2026-10-12/`. It contains security reports, browser reports, screenshots, response results, and file hashes. The `release.json` record identifies the final browser totals, source commit, Cloudflare build result, and public target.

The initial browser procedure exposed a Safari shortcut assumption in the test. Safari uses Option-Tab for links by default. The test uses that shortcut, as stated in the [Apple guide](https://support.apple.com/guide/safari/keyboard-shortcuts-and-gestures-cpsh003/mac).

A second browser procedure exposed clipping at 200 percent root text size. The source repairs address the name and navigation. The saved evidence retains both initial procedures and their failures. The final procedure uses a committed source revision.

## Design findings

The current home page repeats the main navigation and gives no direct contact action. Writing has the same navigation weight as work and contact. Direction repeats subjects from the work summaries and essays.

The site can remain useful without frequent posts. The recommended next design is a compact professional profile with selected work and a contact action. Keep Writing as a secondary collection of essays.

The other options are a single-page professional card and a portfolio of selected work. Read [the design review plan](design-review-plan.md) for structures, content decisions, and review steps. No redesign is part of this dependency release.

## Limits and follow-up

Automated accessibility results do not establish that every visitor can use the site. Screenshot review adds visual evidence. A human review must establish clarity and visitor understanding.

No real-user performance history exists for the new build in this audit. Browser timings are controlled measurements. They are not field Core Web Vitals.

The current content does not support stronger claims about employers, project results, or numerical outcomes. Obtain approved facts before adding those details.

Connecting `putnam.io` to Cloudflare is separate from this release. That change can replace the currently public WordPress site and its old article addresses. Plan the content migration and redirects before a domain change.
